# 🎵 lyrics-viewer

**把你買的專輯和歌詞匯入 ・ 邊聽歌邊練習打 Call ・ 整個程式只有一個 HTML 檔 ・ 不會上傳任何東西 ・ 100% AI Slop**

## ✨ 可以做什麼

- 🎤 **歌詞跟著音樂亮起**：唱到哪一句，那一句就變亮，點任何一行就能跳到那裡
- 🔦 **CALL 另外上色**：打 call 的部分用紫粉色顯示，練 call 用
- 📱 **手機直接開**：不用安裝 app，一個 HTML 檔就是整個播放器
- 🗂️ **自動認歌**：選好音檔後會自動對到歌詞，下次開啟不用重選

## ⚠️ 請先看這個

這個專案**只有應用程式**，沒有附任何歌詞或音樂。歌詞和音樂都有版權，請只用你**自己合法購買**的專輯來製作，做出來的檔案**限個人使用，不要提供給其他人**。

## 🛠️ 做出你自己的歌詞庫

不需要會寫程式，整理歌詞和對時間的工作交給 AI。

1. **準備 AI 訂閱**：需要有可以讀音源的 AI 訂閱，建議使用 Google AI Pro。
2. **拍下歌詞本**：把你購買的專輯中的歌詞本拍照，有點模糊也沒關係。
3. **下載音源**：把從 mora 購買的音源下載下來。
4. **下載播放器**：到 [Releases](https://github.com/damikenx3/lyrics-viewer/releases/latest) 下載最新版的壓縮檔。
5. **選擇模式**：建議用「任務」模式，搭配 Argon 模型。
6. **加入附件**：把步驟 4 的壓縮檔、步驟 2 的歌詞本照片、步驟 3 的音源，全部加入附件。
7. **貼上提示詞**：把下面這段貼進去送出。
   ```text
   附件內提供歌詞應用程式壓縮檔及歌詞和音源檔，請依據提供的音效及歌詞，建立歌詞檔標上每一句歌詞出現確切的時間，時間盡可能精確，文字必須與提供的檔案完全一致，歌詞檔的規格詳壓縮檔中的docs\lyrics-format.md，完成後貼給我確認，或等我傳下一首，我確認完成後執行npm run share把打包完的html給我
   ```
8. **收下成品**：你會拿到一個 HTML 檔。這個檔案**限個人使用，不要提供給其他人**。

## 📱 在手機上使用

1. 把拿到的 HTML 檔複製到手機，例如「Download」資料夾。
2. 在「檔案」app 點開它，選擇 **Chrome** 開啟。
3. 第一次使用時按「加入檔案」，選擇你的音檔（長按可以多選）。之後再開就不用重選。
4. 每次都從**同一個資料夾**開啟。換一個資料夾開，就會像第一次使用一樣要重選音檔。
5. 歌詞有更新時，用同樣的檔名覆蓋手機上的舊檔就好，音檔不用重選。

<details>
<summary>❓ 遇到問題</summary>

- **畫面不會動、按了沒反應**：請選 Chrome 開啟。選「HTML Viewer」的話，畫面不會動。
- **在網址列輸入檔案路徑被拒絕**：Chrome 不允許，請從「檔案」app 點開。
- **歌曲沒有自動對到音檔**：按歌曲旁邊的音符＋加號，手動選這首歌的音檔。
- **音檔播不出來**：畫面會寫原因，通常把音檔轉成 MP3 或 M4A 再選一次就好。
- **播放時螢幕會自己關掉**：從「檔案」app 開啟的頁面無法保持螢幕常亮，請到系統設定把螢幕逾時調長。
- **之前選過的音檔又要重選**：手機空間不足時，瀏覽器可能清掉記住的音檔，再選一次就好。

</details>
